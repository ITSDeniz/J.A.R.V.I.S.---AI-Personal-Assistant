# J.A.R.V.I.S. Audio Assets

Drop your favorite startup track or audio clip here!

### Recommended:
Name your audio file:
`intro.mp3` or `intro.wav` (e.g. AC/DC - Highway to Hell)

### How it works:
- When J.A.R.V.I.S. boots up with `--boot --music` or you say *"Jarvis, play Highway to Hell"*:
- If `intro.mp3` is present here, J.A.R.V.I.S. plays it directly with **zero delay, zero ads, and zero skips** through macOS CoreAudio.
- If not present, J.A.R.V.I.S. delegates playback to Spotify.
